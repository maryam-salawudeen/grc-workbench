# Security policy

GRC Workbench is a learning and portfolio project. If you find a security problem, please report it privately through [GitHub security advisories](https://github.com/maryam-salawudeen/grc-workbench/security/advisories/new) rather than opening a public issue.

Please include the page or endpoint, steps to reproduce and the impact. Reports are usually acknowledged within a week.

The hosted version keeps each visitor's data in their own browser and stores nothing on the server. The only server endpoint, `/api/site-check`, performs a passive, read-only check of a public website and refuses private and internal addresses.
